# docs/

Documentação do projeto lawdog.

## Estrutura

| Caminho | O que contém |
|---|---|
| `BACKLOG.md` | Melhorias futuras, decisões pendentes e ideias identificadas mas não implementadas. Lido no início de qualquer nova sessão de desenvolvimento. |
| `superpowers/specs/` | Design specs aprovados — descrevem *o quê* e *por quê* antes de qualquer implementação. |
| `superpowers/plans/` | Planos de implementação executados por agentes — descrevem *como*, task a task. |

## Convenção

- **BACKLOG.md** é o ponto de entrada para sessões futuras. Toda ideia que não
  vai ser implementada agora vai para cá, com contexto suficiente para ser
  retomada sem precisar reconstruir o raciocínio.
- **specs/** e **plans/** são artefatos de sessões passadas — referência histórica,
  não atualizados retroativamente.
- Novos specs e plans seguem o padrão `YYYY-MM-DD-<tema>.md`.
