# audio2text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/lawdog:audio2text` skill that transcribes audio/video files using faster-whisper locally, saves a timestamped markdown transcript to `docs/`, and integrates into `/lawdog:juntada` with a user confirmation step before background transcription.

**Architecture:** Pure Python script (`audio2text.py`) with PEP 723 inline deps (`faster-whisper`) — zero install, `uv run` resolves on demand. DRY ffmpeg path via `setup.sh` exports `FFMPEG`/`FFPROBE`/`LAWDOG_WHISPER_MODEL` so all scripts read env vars. Juntada detects audio/video → prompts user with 🎙️ confirmation column → dispatches audio2text as background subagent.

**Tech Stack:** Python 3.10+, `faster-whisper>=1.0.0` (PEP 723), `ffmpeg` (audio extraction from video), `uv run`, bash (setup.sh, Makefile), existing lawdog skill patterns.

- Subject lines ≤ 50 chars; signed commits (`git commit -S`)
- All model-facing content (scripts, SKILL.md, tests) in English; user-facing messages in Portuguese
- `FFMPEG` env var = single source for ffmpeg binary path; read via `os.environ.get('FFMPEG', 'ffmpeg')`
- `LAWDOG_WHISPER_MODEL` default = `small` (244MB, good PT-BR quality)
- Script output: silent during processing (`-loglevel error`), only start/mode/done to stderr — no token flood
- Commit and push to bare after each task: `export SSH_AUTH_SOCK=$(gpgconf --list-dirs agent-ssh-socket) && git push bare main`

detect_ffmpeg_path() {
    # Prefer ~/bin/ffmpeg (full build with libx264 etc.) over system ffmpeg
    if [ -x "$HOME/bin/ffmpeg" ]; then
        echo "$HOME/bin/ffmpeg"
    elif command -v ffmpeg >/dev/null 2>&1; then
        command -v ffmpeg
    else
        echo ""
    fi
}

detect_ffprobe_path() {
    if [ -x "$HOME/bin/ffprobe" ]; then
        echo "$HOME/bin/ffprobe"
    elif command -v ffprobe >/dev/null 2>&1; then
        command -v ffprobe
    else
        echo ""
    fi
}

write_tool_paths() {
    local profile="$1"
    local ffmpeg_path ffprobe_path

    ffmpeg_path=$(detect_ffmpeg_path)
    ffprobe_path=$(detect_ffprobe_path)

    # Remove existing lines (idempotent)
    grep -v "^export FFMPEG=\|^export FFPROBE=\|^export LAWDOG_WHISPER_MODEL=" \
        "$profile" > "${profile}.tmp" 2>/dev/null || true

    if [ -n "$ffmpeg_path" ]; then
        printf 'export FFMPEG="%s"\n' "$ffmpeg_path" >> "${profile}.tmp"
        printf 'export FFPROBE="%s"\n' "$ffprobe_path" >> "${profile}.tmp"
        print_ok "ffmpeg: $ffmpeg_path"
    else
        print_warn "ffmpeg não encontrado. /lawdog:video2forum e /lawdog:audio2text não funcionarão."
        print_warn "Instale em: https://www.ffmpeg.org/download.html"
    fi

    # Whisper model size for audio2text — small = 244MB, good PT-BR quality
    printf '# Whisper model for /lawdog:audio2text (tiny/base/small/medium/large-v3)\n' \
        >> "${profile}.tmp"
    printf 'export LAWDOG_WHISPER_MODEL=small\n' >> "${profile}.tmp"

    mv "${profile}.tmp" "$profile"
}

import subprocess
from pathlib import Path

# Use custom ffmpeg if available (system may lack codecs)

def run(args: list[str], env: dict | None = None) -> subprocess.CompletedProcess:
    e = os.environ.copy()
    if env:
        e.update(env)
    return subprocess.run(
        ["uv", "run", str(SCRIPT)] + args,
        capture_output=True, text=True, env=e,

def make_wav(path: Path, duration: float = 1.0) -> None:
    """Create a synthetic WAV audio file using ffmpeg."""

```python
#!/usr/bin/env python3
# /// script
# dependencies = ["faster-whisper>=1.0.0"]
# ///
"""Transcribe audio/video files using faster-whisper (local, PT-BR optimized).

For video files: extracts audio with ffmpeg, then transcribes.
Output: timestamped markdown transcript saved to output path.

Usage:
    uv run audio2text.py -i <file> -o <transcript.md> [--model small] [--lang pt]

Environment:
    FFMPEG              — path to ffmpeg binary (default: ffmpeg in PATH)
    LAWDOG_WHISPER_MODEL — whisper model size (default: small)

Exit codes:
    0: success
    1: input file not found or unsupported format
    2: ffmpeg audio extraction failed
    3: transcription failed
"""
import argparse
import os
import subprocess
import sys
import tempfile
from datetime import date
from pathlib import Path

VIDEO_EXTENSIONS = {'.mp4', '.mov', '.avi', '.mkv', '.webm', '.m4v', '.3gp'}
AUDIO_EXTENSIONS = {'.mp3', '.wav', '.m4a', '.ogg', '.flac', '.aac', '.opus', '.weba'}


def get_ffmpeg() -> str:
    return os.environ.get('FFMPEG', 'ffmpeg')


def extract_audio(video_path: str, output_wav: str) -> None:
    """Extract mono 16kHz WAV from video. Exits with code 2 on failure."""
    ffmpeg = get_ffmpeg()
    result = subprocess.run(
        [ffmpeg, '-nostdin', '-loglevel', 'error',
         '-i', video_path,
         '-vn', '-ar', '16000', '-ac', '1', '-f', 'wav',
         '-y', output_wav],
        capture_output=True, text=True,
    )
    if result.returncode != 0:
        print(f"ERROR: ffmpeg audio extraction failed: {result.stderr}", file=sys.stderr)
        sys.exit(2)


def format_time(seconds: float) -> str:
    m, s = divmod(int(seconds), 60)
    h, m = divmod(m, 60)
    return f"{h:02d}:{m:02d}:{s:02d}" if h else f"{m:02d}:{s:02d}"


def transcribe(audio_path: str, model_name: str, language: str) -> tuple:
    """Run faster-whisper. Returns (segments_list, info). Exits 3 on failure."""
    try:
        from faster_whisper import WhisperModel
    except ImportError:
        print("ERROR: faster-whisper not available. Run: uv run audio2text.py ...", file=sys.stderr)
        sys.exit(3)

    try:
        print(f"  Loading model '{model_name}'...", file=sys.stderr)
        model = WhisperModel(model_name, device='cpu', compute_type='int8')

        print("  Transcribing...", file=sys.stderr)
        segments_iter, info = model.transcribe(audio_path, language=language, beam_size=5)

        segments = [
            {'start': seg.start, 'end': seg.end, 'text': seg.text.strip()}
            for seg in segments_iter
        ]
        print(
            f"  Language: {info.language} "
            f"(confidence: {info.language_probability:.0%})",
            file=sys.stderr,
        )
        return segments, info
    except Exception as e:
        print(f"ERROR: transcription failed: {e}", file=sys.stderr)
        sys.exit(3)


def write_transcript(output_path: str, input_name: str, segments: list,
                     info, model_name: str) -> None:
    """Write timestamped markdown transcript with legal analysis placeholder."""
    duration = segments[-1]['end'] if segments else 0.0

    lines = [
        f"# Transcrição: {input_name}",
        "",
        f"**Arquivo:** {input_name}",
        f"**Duração:** {format_time(duration)}",
        f"**Idioma detectado:** {info.language} "
        f"(confiança: {info.language_probability:.0%})",
        f"**Modelo:** faster-whisper {model_name}",
        f"**Data:** {date.today().isoformat()}",
        "",
        "---",
        "",
        "## Texto",
        "",
    ]

    if segments:
        for seg in segments:
            lines.append(f"[{format_time(seg['start'])}] {seg['text']}")
    else:
        lines.append("*(nenhuma fala detectada)*")

    lines.extend([
        "",
        "---",
        "",
        "## Análise Jurídica",
        "",
        "*(Preenchida por Dr. LawDog após a transcrição)*",
        "",
        "**Relevância para o caso:** [a preencher]",
        "",
        "**Pontos chave:**",
        "- [a preencher após leitura]",
        "",
        "**Artigos aplicáveis:** [a verificar via knowledge/ ou fetch-law]",
    ])

    Path(output_path).write_text('\n'.join(lines), encoding='utf-8')


def main() -> None:
    parser = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter,
    )
    parser.add_argument('-i', '--input', required=True,
                        help='Input audio or video file')
    parser.add_argument('-o', '--output', required=True,
                        help='Output markdown transcript path')
    parser.add_argument('--model',
                        default=os.environ.get('LAWDOG_WHISPER_MODEL', 'small'),
                        help='Whisper model (default: $LAWDOG_WHISPER_MODEL or small)')
    parser.add_argument('--lang', default='pt',
                        help='Language hint (default: pt for Brazilian Portuguese)')
    args = parser.parse_args()

    input_path = Path(args.input)
    if not input_path.exists():
        print(f"ERROR: Input not found: {args.input}", file=sys.stderr)
        sys.exit(1)

    ext = input_path.suffix.lower()
    print(f"Processing: {input_path.name}", file=sys.stderr)

    if ext in VIDEO_EXTENSIONS:
        with tempfile.NamedTemporaryFile(suffix='.wav', delete=False) as tmp:
            tmp_wav = tmp.name
        try:
            print("  Extracting audio from video...", file=sys.stderr)
            extract_audio(str(input_path), tmp_wav)
            segments, info = transcribe(tmp_wav, args.model, args.lang)
        finally:
            Path(tmp_wav).unlink(missing_ok=True)
    elif ext in AUDIO_EXTENSIONS:
        segments, info = transcribe(str(input_path), args.model, args.lang)
    else:
        print(f"ERROR: Unsupported format: {ext}", file=sys.stderr)
        print(f"  Video: {sorted(VIDEO_EXTENSIONS)}", file=sys.stderr)
        print(f"  Audio: {sorted(AUDIO_EXTENSIONS)}", file=sys.stderr)
        sys.exit(1)

    write_transcript(args.output, input_path.name, segments, info, args.model)
    size = Path(args.output).stat().st_size
    print(f"Done: {args.output} ({size} bytes, {len(segments)} segments)", file=sys.stderr)


if __name__ == '__main__':
    main()
```

## Protocolos importados

Read `protocols/document-standards.md` when writing the legal analysis section.
Read `protocols/knowledge-sources.md` when identifying applicable legal articles.

## Trigger

User submits audio/video and asks what is being said, or
`/lawdog:juntada` detects audio/video and user marks it for transcription.

Direct use: `/lawdog:audio2text -i <file>`

## Fluxo

### Step 1 — Run the script

```bash
CASES_DIR="${LAWDOG_CASES_DIR:-$HOME/lawdog-cases}"
OUTPUT="$CASES_DIR/<slug>/<petition>/docs/transcricao-<filename>.md"

uv run "${CLAUDE_SKILL_DIR}/scripts/audio2text.py" \
    -i "<input-file>" \
    -o "$OUTPUT" \
    --lang pt
```

The script is silent during transcription — only prints start/mode/done.
It handles video automatically (extracts audio with ffmpeg before transcribing).

### Step 2 — Read the transcript

After the script completes, read the generated `docs/transcricao-<filename>.md`.

### Step 3 — Complete the legal analysis section

In the transcript file, replace the placeholder `## Análise Jurídica` section
with Dr. LawDog's analysis:

- **Relevância para o caso:** High/Medium/Low — concrete reason
- **Pontos chave:** specific timestamped quotes that are legally significant
  (admissions, contradictions, key facts, dates mentioned)
- **Artigos aplicáveis:** verified via `knowledge/` or `/lawdog:fetch-law`

Apply all quality rules from `protocols/document-standards.md`:
no filler, no speculation, cite only verified articles.

### Step 4 — Report to user

Summarize in Portuguese:
- What was transcribed and how long
- Key legally significant statements (with timestamps)
- How this evidence strengthens or weakens the case

## Gotchas

- **Model download on first run.** The `small` model (~244MB) downloads
  automatically via `uv run`. This takes 1-5 minutes on first use.
  Subsequent runs are fast. Do NOT warn the user before every transcription —
  only if the download seems to be hanging.
- **FFMPEG must be set** for video inputs. setup.sh exports it. If unset,
  the script uses system `ffmpeg` which may lack codecs for some formats.
- **Legal analysis is Dr. LawDog's job, not the script's.** The script only
  produces the transcript. Dr. LawDog reads it and writes the analysis.
  Never leave the analysis section as a placeholder — always complete it.
- **Synthetic audio in tests.** Tests use ffmpeg-generated sine-wave audio
  (no real speech). Whisper will transcribe noise or silence — that is correct
  behavior for testing. Don't confuse test output with production quality.
